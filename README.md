# Blockbench Pack Creator

Create, organize, check, and export Minecraft Java item resource packs from Blockbench models in your browser.

Blockbench Pack Creator is an independent community tool. It is not affiliated with, endorsed by, or sponsored by Mojang, Microsoft, or the Blockbench project.

## Features

- Start a new resource pack or open and merge an existing ZIP pack.
- Import `.bbmodel` and JSON model files.
- Assign Minecraft items and Custom Model Data values, then organize models into folders.
- Edit, search, filter, and validate pack contents.
- Choose a target pack format or enter a custom format range.
- Export the full pack, a folder, or selected models as ZIP files.
- Switch the interface between German and English.

## Getting started

1. Download `blockbench-pack-creator.html` from this repository.
2. Open it in a recent desktop browser. An internet connection is required to load JSZip, which the app uses to read and create ZIP files.
3. Start with an empty pack or load an existing resource-pack ZIP.
4. Import `.bbmodel` or `.json` files, set their item and model values, and add them to the pack.
5. Run **Check pack**, review any findings, then download the pack as a ZIP.

No installation, account, or build step is required.

Pack files are processed in your browser; this app does not upload them to a project server. The app stores your language and day/night display preference in browser local storage. It loads JSZip from cdnjs and optional fonts from Google Fonts, so those services receive ordinary requests when the page loads.
